# Bharat Collections Agents - Built for Bharat

Submitting for The Great Indian AI Internship Challenge by Gnani AI

Live Demo: https://bharat-collections-agents.onrender.com

### The Problem
Collection agents in India struggle - Customers speak Telugu, Hindi, Tamil, English - all mixed in one call. Agents miss payment promises, use wrong language, lose trust.

### The Solution
Bharat Collections Agents is a Voice AI agent that understands 11 Indian languages.

How it works:
1. Upload any file (PDF, .json, CSV) - Customer data
2. AI understands voice in Telugu / Hindi / Tamil / English
3. Detects Intent - PAYMENT PROMISE, DISPUTE, CALLBACK
4. Replies in customer's own language instantly

Example:
User typed in Telugu: "nenu repu kathesthanu"
AI detected: Telugu | PAYMENT_PROMISE
AI replied in Telugu instantly.

### Gnani AI Models Used
- Prisma - Speech to Text for Telugu voice
- Timbre - Text to Speech for replies
- Evon - For intent detection

### Tech Stack
Python, Flask, Render, Gnani AI APIs
